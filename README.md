# 🍕 SQL Pizza Sales Analysis


## 📌 Project Overview

This project demonstrates how SQL can be used to analyze a pizza sales database by solving real-world business questions. The main objective is to practice writing SQL queries using different SQL concepts such as filtering, sorting, grouping, joining multiple tables, and aggregate functions.

The project focuses entirely on SQL query writing and data retrieval from a relational database.

---

## 🎯 Objectives

* Practice SQL using a real-world dataset.
* Improve query writing skills.
* Retrieve meaningful business information from multiple tables.
* Understand relationships between tables using JOIN operations.
* Perform sales analysis using SQL.

---

## 🛠️ Technologies Used

* MySQL
* SQL
* Relational Database

---

## 📂 Dataset

The project uses a pizza sales dataset containing information about:

* Orders
* Order Details
* Pizzas
* Pizza Types

These tables are related through primary and foreign keys, allowing business-related queries to be performed.

## ▶️ How to Run

1. Clone this repository.

```bash
git clone https://github.com/Vivek-bisht98/SQL-pizzas-analysis.git
```

2. Open MySQL Workbench (or any MySQL client).

3. Create a database.

```sql
CREATE DATABASE pizza_db;
```

4. Import the dataset into the database.

5. Execute the SQL queries provided in `queries.sql`.
